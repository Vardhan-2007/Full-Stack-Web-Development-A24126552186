# Lab Task 1 · Basic HTML Tags and Resume
**Aim:** Use the basic HTML tags (headings, text formatting, lists, links, image, table with colspan/rowspan, form controls, semantic tags) on one page, and build a resume page with HTML only.

- `src/index.html` - every basic tag, one section at a time
- `src/resume.html` - resume using tables, lists and headings

**Run:** open `src/index.html` in a browser; the resume is linked from it.
