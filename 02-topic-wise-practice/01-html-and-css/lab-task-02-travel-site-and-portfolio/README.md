# Lab Task 2 · Travel Website and Portfolio
**Aim:** Build a multi-section travel website and a personal portfolio with external CSS, Grid and Flexbox layouts, and a media query for mobile.

- `src/travel-site/` - "Explore Andhra": sticky header, hero, place cards in a CSS grid, trip-planning form, footer
- `src/portfolio/` - About, Skills, Projects and Contact sections

**Run:** open each `index.html` in a browser. Resize the window below 600px to see the mobile layout.
