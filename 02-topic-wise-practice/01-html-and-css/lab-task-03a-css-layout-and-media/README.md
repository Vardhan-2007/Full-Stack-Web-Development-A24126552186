# Lab Task 3a · CSS Layout, Positioning and Media
**Aim:** Demonstrate Flexbox (justify-content, align-items, direction, wrap, grow), the five position values (static, relative, absolute, fixed, sticky), and embedding content with `<iframe>`, `<audio>` and `<video>`.

**Run:** open `src/index.html`. To play audio/video, add `sample-audio.mp3` and `sample-video.mp4` to `src/media/`.
