# Node.js and Express Practice
| File | What it shows | Run | Port |
|---|---|---|---|
| `basic-http-server.js` | Routing with the built-in `http` module, query strings, JSON and 404 responses | `npm run http` | 4000 |
| `express-middleware-demo.js` | Built-in, custom, route-level, router-level, 404 and error-handling middleware | `npm run middleware` | 4001 |
| `rest-api-crud.js` | REST CRUD on an in-memory course list with validation and status codes | `npm run crud` | 4002 |

Run `npm install` first. For the middleware demo, `/secret` needs the header `x-api-key: fsd-lab`.
