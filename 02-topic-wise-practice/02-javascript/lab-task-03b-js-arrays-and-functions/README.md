# Lab Task 3b · JavaScript Arrays and Functions
**Aim:** Seven programs on arrays and functions.

1. Sum, average, largest and smallest of an array
2. `map`, `filter` and `reduce` on marks
3. Sorting an array of objects
4. Removing duplicates with `Set` and counting frequency
5. Function declaration, function expression, arrow function, default parameters
6. Callbacks and higher-order functions
7. Closures and recursion

**Run:** open `src/index.html` in a browser, or run `node src/programs.js`.
